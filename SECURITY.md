# Security Policy

Installers in this repository are built from
[DeYinAI/deyin-desktop](https://github.com/DeYinAI/deyin-desktop). Report security
issues against the product there or by email — not via public issues on this repo.

## Supported versions

| Version | Supported |
| --- | --- |
| Latest [GitHub Release](https://github.com/DeYinAI/deyin-releases/releases/latest) | yes |
| Older releases | best effort |

## Reporting a vulnerability

**Do not open public GitHub issues for security vulnerabilities.**

Email **hello@deyin.ai** with:

- Description of the issue and impact
- Steps to reproduce
- Affected release version (e.g. `v1.0.0`) and platform

We aim to acknowledge within 72 hours and provide a remediation timeline for confirmed
issues.

## Source repository

Vulnerability fixes are developed in
[deyin-desktop](https://github.com/DeYinAI/deyin-desktop) and shipped here on the next
tagged release. See that repo's [SECURITY.md](https://github.com/DeYinAI/deyin-desktop/blob/main/SECURITY.md)
for automated scanning and supported development branches.
